1. TECH SUB BUILDER HIDDEN
--------------------------
HIDDEN, NOT DELETED - the page still exists, so remove `hidden: true` in
lib/designShell.js to bring it back rather than rebuilding it.

lib/designShell.js already had `internalOnly`, which hides builder tools from
customers. It had no way to hide something from EVERYONE, so `hidden` is added
and honoured alongside it - the same convention pkg898 added to
components/OperationsNav.js, so both areas now hide the same way.

Design tabs after this: Handover Docs, RFIs, Tech Sub, Rock Drawings,
Calculations, Leak Test Certs, Warranties, O&Ms.


2. THE BACK BUTTON ON DESIGN CUSTOMERS
--------------------------------------
It was decided by ROLE:

    href={me.role === 'management' ? '/design' : '/admin'}

But the page is reached from BOTH places - Admin lists it, and the Design portal
has a "Manage Customers" link. So:

    an admin arriving from Design      -> sent to Admin      wrong
    an admin arriving from Admin       -> sent to Admin      right
    a management user from Admin       -> sent to Design     wrong
    a management user from Design      -> sent to Design     right

Right for one route in and wrong for the other, for every role. Yours was the
first case.

It now follows the route actually taken: the Design portal's link carries
?from=design, and the back button reads it. Where there is no marker - an old
bookmark, or somebody typing the address - it falls back to the old role guess
rather than picking arbitrarily.

The label follows too, so it says "Design" when it goes to Design.
