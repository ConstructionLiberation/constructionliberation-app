pkg893 - Type a recipient, and a chart that fits a long project
===============================================================

TWO FILES, neither new. The project folder uses literal square brackets.
  pages/applications.js
  pages/project/[id].js


1. TYPE AN ADDRESS WHEN THERE IS NOBODY TO PICK
-----------------------------------------------
The TO field on "Send application to customer" was a dropdown built from the
project's own contacts and the portal users. A project with NO CUSTOMER ASSIGNED
offered nothing but "Select a recipient", and there was no way past it.

So the application could not be sent at all until somebody went and edited the
project first. Reasonable to want to do eventually; ridiculous to be forced into
at the moment you are trying to send.

There is now a "Type an address..." option at the bottom of the list, which
swaps the dropdown for a text box. On a project with NO contacts it starts in
that mode already, so the field is usable straight away rather than after
working out that the dropdown is empty.

A TYPED address is validated; a picked one is not, because it came from a list
and is already known good. An application that silently goes nowhere because of
a missing dot is worse than one that refuses to send.

CC is unchanged - it already had a free-text box.


2. THE MONTHLY INVOICING CHART ON A LONG PROJECT
------------------------------------------------
The width was fixed at 420px and the months divided it up. Russell Hill spans 22
months, so each got about 17px - the value labels and the month labels both
overlapped into the smear in your screenshot.

Shrinking the font would have made it unreadable a different way. Each month now
gets a minimum of 46px and the chart scrolls sideways when there are more than
fit:

     3 months ->  420px wide, 118px per month
     6 months ->  420px wide,  59px per month
    12 months ->  618px wide,  46px per month
    22 months -> 1078px wide,  46px per month
    30 months -> 1446px wide,  46px per month

A short project looks EXACTLY as it did - the width only grows once 46px per
month no longer fits in 420. So nothing changes for most projects.
