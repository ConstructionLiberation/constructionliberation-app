A TEMPLATE EVERY QUOTE FOLLOWS: a quote's letter IS the company template -
live - unless it is changed for that quote. The Letter tab says "using the
company template" or "customised for this quote"; typing makes a copy for this
quote only (the template is not changed); "Reset to template" goes back.
Change the template and every quote using it follows. ISSUING freezes the
letter as it reads with the revision - a later template change never rewrites
a quote that has gone out.
EDIT TEMPLATE - admins have "Edit template" on the Letter tab: edit the company
letter there, with the placeholder buttons, and Save template. (Admin > Quote
Documents edits the same template.)
RED TEXT - select words in the letter and "Make red": they show red on the
letter and on the printed quote ([red]...[/red] in the text box). "Clear red"
- click inside red text, or select it - removes it.

NOTE: quotes whose letter was copied in before this change (e.g. TEST PROJECT)
count as customised - use "Reset to template" on them to follow the template.
