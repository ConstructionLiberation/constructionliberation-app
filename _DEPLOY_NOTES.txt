THE BUILD-UP EDITOR
  SIZE: one per build-up (e.g. Girth 0.6). A new APPLY SIZE tick column after
    Item: a ticked line's quantity is multiplied by the size. Size sums from the
    converted spreadsheet (Size1+0.2...) still work.
  ⚙ LIST on each material / labour line: that line's list of products -
    remove those that do not apply to this build-up; search the whole price
    list (or labour rates) and add. Same in the take-off pop-out.
  V (VARIABLE) beside the item, the rate and the waste: marks that cell to be
    reviewed on every quote - it shows LIGHT RED wherever the build-up is used.
  DESCRIPTION box at the bottom - blank to start. Write the text and put
    {products} where the product list goes ("Insert {products}"). "⚙ Products in
    the description" ticks which material lines are included - in build-up
    order, "A, B and C" (a product's price-list description; an own item's
    label). "Reads:" shows the result. On the quote, an item with a description
    uses it as its line.
  PRODUCT RULES removed - waste lives on each line. A rule for a line's chosen
    product is written onto that line's waste when the build-up is opened, so
    nothing changes silently.
  "+ management" removed.

THE BUILD-UPS FILE (download / upload) now also carries: an own item's Rate
(found while building this: from 1097 an own item's typed rate was NOT in the
download - a download and re-upload would have lost it, including the
converted Tape / Solvent rates), Apply size, In description, Variable, and a
Descriptions sheet. Older files still upload.

THE TAKE-OFF AND QUOTE
  - Section headers: no total; BOLD and UNDERLINED (take-off and quote).
  - The quote DATE is not typed any more (gone from the project details): a
    draft shows today's date marked "DRAFT - not yet sent".
  - Quote tab: "Download and mark as sent (Rev A)" - issues the revision (the
    CRM value updates, as with Issue), then opens the print window with the
    quote AS ISSUED (Rev A, today's date, no DRAFT) to save as a PDF; then back
    to the next draft (Rev B). "Print draft" prints the draft.
