PACKAGE 1079 - Retention tracker: Export to Excel, choosing the columns

One file. Complete replacement. No re-seed. No env changes. Built on 1078.

  pages/retention.js

"Export to Excel" sits beside Import spreadsheet. It opens a window:

  ROWS      As shown (your status filters) - or every project on the register
  COLUMNS   every tracker column, in the table's order, each with a tick box;
            Select all / Clear. Three EXTRA columns are offered that the screen
            only shows as colour: Status, 1st Released?, 2nd Released?
            Your choice is remembered in this browser for next time.
  Download  -> Retention-tracker-<date>.xlsx

The figures are worked out with the SAME functions as the table cells (final
account, account remaining, retention owed, release values, VAT, totals, the
two match columns as Yes/No and Ties/Deducted out/Released out/Both out), so
the spreadsheet always matches the screen. Money columns are real numbers
formatted #,##0.00, so they can be summed. 0%-retention release cells and the
reconciliation for projects with no 612 lines are left blank, as on screen.

On the full Retention page only - the read-only copy inside Bookkeeping has no
buttons, as before.

Checked: a workbook built from two sample projects with the page's OWN
calculation code and read back - every figure verified by hand (Account
Remaining 10,493.22 = Final Account - Applied for; Retention Owed 7,230.52 =
3% of invoiced, reconciliation "Ties"; 1st Value 4,112.07; VAT 0 on reverse
charge and 19,500 at 20%; Total Remaining 44,138.21 and 17,000), money
formatted as numbers, 0%-retention and no-612 cells blank. The tracker and the
Bookkeeping page bundle; all 158 pages pass the browser check.
