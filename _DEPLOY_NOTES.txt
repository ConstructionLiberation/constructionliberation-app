In a build-up's Sizes block, each size (Width, Height, Girth) has a MANDATORY
tick. Leave the value blank on the template; on every quote using the
build-up a number must be entered:
  - the size box is RED ("required") in the pop-out until it has a number
  - the take-off shows "Width required" (etc.) in red on the item
  - Issue / Download and mark as sent are REFUSED, listing what is missing
    ("Enter the mandatory sizes first: Mech fixed single ply - Width") - and the
    server refuses too, so it cannot be bypassed
The build-ups file carries it (a Mandatory column on the Sizes sheet).
