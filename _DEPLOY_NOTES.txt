The description box no longer shows {products} codes. It shows the
description as it will read on the quote:
  - INSERT PRODUCTS puts the ticked products in LIGHT GREY where the cursor is
    ("Alkorplus polythene VCL and CX Plate for PVC 6.5mm Hole"). Grey text is
    LIVE: tick or untick a product under ⚙ (or change a product) and it updates.
  - INSERT VARIABLE does the same with the variable's value (e.g. "20 year").
  - Everything is editable, typed straight into the box. Typing at the start or
    end of grey text adds your own words beside it - the grey stays live.
    Changing anything INSIDE grey text makes it your own wording: black, and no
    longer updated.
  - Pasting brings in plain text only.
The quote prints exactly what the box shows. Saved in the same form as before,
so existing descriptions, the quote and the build-ups file are unchanged.
