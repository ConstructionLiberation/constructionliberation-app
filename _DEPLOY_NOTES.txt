PACKAGE 930 - Rock Roofing's pipeline was being shipped to every tenant
================================================================================

Three files. Complete replacements. Nothing new to create.

  lib/crmSeedDeals.js        339 KB -> 1.3 KB
  pages/crm.js               one dead import removed
  pages/api/crm.js           first-run seeding now returns nothing

DEPLOY THIS BEFORE ANYTHING ELSE ON THE LIST.


WHAT WAS HAPPENING
==================
lib/crmSeedDeals.js held 378 real Rock Roofing deals - six months of live
pipeline. Main contractor names, named contacts, site addresses, tender values,
credit scores, credit limits, lost reasons, and internal commercial notes of the
"Decline & send to Hoyes roofing" kind.

Two separate paths put it where it should never have been:

1. pages/crm.js imported SEED_DEALS on line 17 AND NEVER USED IT. A dead import
   - but an import is enough. The whole 339 KB was compiled into the client
   bundle and served to the browser of anyone who opened the CRM, on any
   tenant, on any hostname.

2. pages/api/crm.js seeded it as the starting data for any tenant whose
   crm:deals key was absent. A brand-new customer's CRM opened showing Rock's
   pipeline as though it were their own.

Found on zztest: a tenant whose database contained exactly two keys displayed
Rock's entire pipeline. find-string on that host reported found: 0, correctly -
nothing had crossed between databases. It was compiled in. The database
isolation work does not touch this axis at all.


WHAT CHANGED
============
- The import is gone from pages/crm.js. Nothing else in that file referenced it.
- pages/api/crm.js no longer imports it; loadDeals() returns an empty array on
  first run, with _wereSeed false.
- lib/crmSeedDeals.js is a stub exporting an empty array, with the history
  written into it so nobody refills it.


SMOKE TEST
==========
1. app.rockroofing.co.uk -> CRM. Rock's real deals still load, because they come
   from crm:deals in Rock's database, not from the seed. THIS IS THE ONE THAT
   MATTERS - if Rock's CRM is empty after this deploy, stop and tell me.
2. zztest.constructionliberation.com -> CRM. Expect an empty CRM. Before this
   package it showed Rock's pipeline.
3. The CRM page should also load noticeably faster; 339 KB has come out of the
   bundle.
