ESTIMATING > RATE BUILD-UPS
  Categories down the left (+ No category, flagged); rename or delete a
  category (its build-ups move to No category). Search across all build-ups.
  Open a build-up -> the editor:
    - name, category, unit (m2, m, nr, item)
    - SIZES (Size1...) that quantities can use; renaming a size renames it in
      the quantities
    - LINES: material | labour | fixed rate | lump sum | comment, reorder,
      add, remove; + management (left out by default)
        product / labour picked from the LINE'S OWN LIST; tick "any product" to
        pick from the whole price list (it is added to the line's list)
        RATE: type over it to change it - shown CHANGED, with Revert to price list
        quantity (number or a sum like Size1*1.1), waste %, price increase %,
        cost category, the line's cost
    - PRODUCT RULES: this product on this line -> waste %
    - TRY THE RATE: profit %, MCD %, labour factor -> materials, labour,
      profit, MCD and the rate (for trying - estimates will set their own)
    - Save (override template) | Save as new template | Delete
  Upload (checked first; errors block), Download, Blank template.

THE RATE (lib/buildups.js):
  material = rate x qty x (1 + waste + increase); fixed = amount x qty x (1 + waste)
  labour = rate x qty x labour factor; profit on the subtotal;
  rate = (subtotal + profit) / (1 - MCD)  - EXACT; rounded UP to the penny.
  No lodge, no management unless added. Lump sums price on the estimate.
