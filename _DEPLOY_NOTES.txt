PACKAGE 1013 - every Certified cell is editable, and what you type stays
================================================================================

One file. Complete replacement. ROCK-LIVE BEHAVIOUR CHANGE.
Includes 970, 971, 982, 1007 and 1011.

  pages/retention.js


UNLOCKING THE CELL WAS ONLY HALF OF IT
================================================================================
The lock was not decoration. The precedence underneath it was:

    a real figure on the latest sent application WINS; typed is a fallback

so removing `disabled` on its own would have restored the exact fault the
lock was built to hide - you type a figure, press Enter, and watch the
application put its own number straight back. That is described in the file,
from when it happened.

So the precedence is reversed as well:

    a typed value WINS; the application is used where nothing has been typed

Checked across every combination:

  typed 12500, app says 9000        -> 12500   [typed]
  nothing typed, app says 9000      ->  9000   [from app]
  typed 12500, app box empty        -> 12500   [typed]
  nothing typed, app box empty      ->     0   [from app]
  nothing typed, no sent application-> blank   [from app]
  typed 0 deliberately              ->     0   [typed]

That last one matters: a deliberate zero is now respected rather than read as
"nothing typed".


THE TRADE, WHICH IS REAL
================================================================================
This reinstates the problem the old rule existed to prevent. A figure typed
today will NOT be refreshed by a later application. A row typed over in
September still shows September's number in December unless somebody updates
it.

That is the cost of editability and there is no version of this that avoids
it - either the application owns the cell or you do.

What the page does instead is make it VISIBLE. The small note beside each
figure now reads:

    typed    - this row is yours to maintain, nothing will update it
    app 7    - taken from application 7, and it will keep up to date

Hovering says the same in full, including how to hand a row back: clear the
cell and it returns to taking the figure from the application.


AMENDMENT, NOT CORRECTION
================================================================================
The original paragraphs are left in the file as written - they explain why
the rule was the other way round and what went wrong before it. A dated note
records the reversal and the reason. Same treatment as the retention basis
change in 1011, and for the same reason: whoever reads this in six months
needs the history, not just the current answer.


SMOKE TEST
================================================================================
1. A row that was greyed out - Certified with an "app N" note - is now
   editable. Type a figure; it sticks through a reload and the note reads
   "typed".
2. Clear that cell. The application's figure returns and the note goes back
   to "app N".
3. A row showing 0.00 with no sent application: type a figure, it stays.
4. The totals row, Retention Owed and the 612 panel all move with the typed
   figure - Certified feeds them, so a manual override now flows through.
