LUMP SUM - a new line type: an amount x the line's quantity, NOT divided by the
item's quantity; no product; ANY cost category (Plant, Subcontract,
Attendances...; a Labour lump sum counts as labour). E.g. Scaffold hire 350
on a per-week item. Listed on the Materials tab under "not from the price
list". (Lump SPREAD is unchanged - an amount per job spread over the qty.)
In the build-ups FILE the new type is written "lump"; "lump sum" / "lump
spread" in a file mean the spread, as in your existing file.

UNITS: weeks and days - for build-ups and items, labour rates and the price
list (e.g. plant hire per week). "weeks" / "days" in a file are read too.

SIZES: WIDTH and HEIGHT for each build-up. "Apply size" on a line is now a
choice: - / Width / Height - the line is multiplied by that one. Girth belongs
in the line rates. Sizes from the spreadsheet stay listed so quantities
written as sums still work; a line set in 1098 keeps applying its size.

VARIABLE DESCRIPTIONS: "Insert variable" asks for a name (e.g. Warranty
period), puts {Warranty period} in the description and lists it with a value
box - LIGHT RED until filled in. The description reads with the value; an
empty one shows [Warranty period]. Each build-up, and each estimate item, has
its own values. The file's Descriptions sheet carries them
("Warranty period=20 year; Colour=Grey").
