PACKAGE 961 - the currency SYMBOL in labels
================================================================================

Four files. Complete replacements. THE SAME FOUR FILES AS 960 - deploy 960
first, check it, then this.

  pages/commercial.js
  pages/retention.js
  pages/applications.js
  pages/variations.js


WHAT IT WAS
================================================================================
960 fixed the figures. Twenty-nine pound signs remained in these four files as
LABELS, which on demo meant a column headed "Profit £" above a column of
dollars:

  commercial    Lab Left £, Mat Left £, Total Left £, Profit £, WIP £
                (in the column list AND again in the legend), plus
                Invoiced £ (inc WIP), Profit £ (inc WIP), WIP £
  retention     Project Value £, Final Account £, Applied for £, Certified £,
                Invoiced Net £, Manual VAT £, Release Value £ (twice),
                and one tooltip reading "Reverse charge / 0% = £0"
  applications  a bare £ prefix on an input, two "this line has a £0 value"
                warnings and the matching cell tooltips
  variations    Materials £, Labour £, Profit £, Total £ in the column list,
                and Materials (£) / Labour / Lodge (£) / Profit (£) twice in
                the add and edit forms

Different mechanism from 960: this is currencySymbol off the same feed, not
money(). Zero figures change.


CHECKED - AND ONE CHECK THAT MATTERS MORE THAN THE COMPILE
================================================================================
A component that USES currencySymbol without destructuring it compiles
perfectly and throws at runtime. So rather than trusting the build, every
occurrence was mapped to its enclosing component and matched against the
declarations:

  commercial   Dashboard           11 uses   declared
  retention    RetentionPage        1 use    declared
  retention    EntryForm            8 uses   declared  (hook added here)
  applications ApplicationEditor    5 uses   declared
  variations   VariationTracker    10 uses   declared

EntryForm is the only component that gained a useFormat() in this package, and
it takes currencySymbol alone - it has no formatted figures in it.

Also: zero visible pound signs remain in any of the four, counted excluding
comments. All four compile and bundle clean with no duplicate symbols.


SMOKE TEST
================================================================================

   headings read $ not £, and so does the legend behind the "?" - it is a

   form.

5. Rock: all four unchanged, reading £ everywhere they did before.
