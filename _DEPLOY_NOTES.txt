A VARIABLES button on the Build-ups page (beside Download / Blank template)
opens the variables manager: every description variable, with how many
build-ups use it. Pick one to:
  - RENAME it - every build-up's description follows
  - change its OPTIONS (one per line; none = a typed value) - each build-up
    keeps its chosen value unless it is no longer offered, then it is cleared
    (shows red) to choose again
  - DELETE it - removed from every build-up and their descriptions
"Save - 2 build-ups" applies to every build-up using it. Quotes already priced
keep their own copies. Available while no build-up is open (so an unsaved
build-up cannot overwrite the change). Clicking a variable's name beside a
build-up's description still edits it for that build-up only.
