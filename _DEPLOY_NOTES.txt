PACKAGE 1054 - Commercial nav: slim on an iPad

One file. Complete replacement. No re-seed. No env changes. Built on 1053.

  components/CommercialNav.js

THE CAUSE
The nav bar is shared by every Commercial page, but three pages put their own
controls INSIDE it, beside the links:

  Project Financials    Budget Tracker / EOM Report switch, month picker,
                        three sync buttons with their last-run times
  Outstanding Invoices  one sync button
  Retention             one sync button

On a desktop they fit. On an iPad Project Financials' controls could not, so
the LINKS wrapped onto extra lines and the bar ballooned.

THE FIX
The main bar now holds only the links and Report app improvement - slim, the
same on every page, like the other portals. A page's own controls sit in a
slim strip directly under it, in the same dark colour so they look as before,
wrapping neatly if the screen is narrow. Pages with no controls get no strip.

Nothing about the controls themselves changes - same switch, same picker,
same sync buttons, same behaviour. On a desktop they now sit in the strip
rather than at the far right of the bar.

Checked: the nav rendered with and without page controls (strip only when
there are controls; controls in the strip, not the bar); every page using the
Commercial nav bundles; all 157 pages pass the browser check.

SMOKE TEST - on the iPad
1. Commercial > Project Financials: the dark bar is one slim row of links; the
   switch, month picker and sync buttons sit in a strip under it.
2. Outstanding Invoices and Retention: same, with their sync button.
3. Applications, WIP etc.: no strip, unchanged.
