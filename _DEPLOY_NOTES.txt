PACKAGE 968 - the fix for the failed builds
================================================================================

ONE file. Complete replacement.

  pages/forms/index.js

This unblocks 965, 966 AND 967 in one go. All three are already committed to
main; they have simply never built, so 964 has remained live throughout.
Nothing needs re-pasting.


WHAT I DID WRONG
================================================================================
pages/forms/index.js has, at line 1436:

    export function Shell({ children, onLogout, user }) {

Shell is the shared Site App chrome, and EVERY page under /forms imports it.
The title and the logo I changed in 965 are inside Shell.

My ownership scan - the one I have been quoting all day as the check that
catches what the compiler misses - matched only

    function X            and      export default function X

and NOT `export function X`. So it could not see Shell at all, and attributed
Shell's lines to FormsList, the previous plain function. I put the hook into
FormsList, which never uses brand, and left Shell referencing a variable that
does not exist.

    ReferenceError: brand is not defined

Sixteen /forms pages failed to prerender. The compile passed cleanly - it
always does for this - and the failure only appeared at static generation.


WHAT I DID ABOUT IT
================================================================================
The hook now sits in Shell, and the one in FormsList is removed.

Then I fixed the scanner and re-ran it over every page and component in the
repo that uses useFormat. Six things came back. Four were my scanner being
wrong about its own output; two more - contracted-rates and
upload-transactions - are real but pre-existing: both still have a
module-scope hardcoded pound formatter, because neither has been converted
yet. They are in the remaining tail, not a regression.

Shell was the only genuine fault. Nothing else from 955 to 967 has an
undeclared reference.
