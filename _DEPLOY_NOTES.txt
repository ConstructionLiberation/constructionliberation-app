PACKAGE 1105 - Build-up lines read Qty x Rate = Line rate, and fit the screen

Three files. Complete replacements. No re-seed. No env changes. Built on 1104.

  components/BuildupEditor.js
  pages/estimating/build-ups.js
  pages/estimating/estimate/[id].js     (folder literally named [id])

The multiplication was always there - "Line cost" was the product rate x Qty
(x waste / increase) - but that column sat off the right edge of the screen.
Now each line reads left to right:
  Type | Label | Item | Apply size | Qty | Rate | Waste % | Incr % | = Line rate | Cost cat.
"= Line rate" (green) is that line's part of the build-up's rate, e.g.
Discs 5 x 0.233 = 1.16.

AND IT FITS: with a build-up open, the Build-ups page gives the editor the full
width (the category and build-up lists fold away; "← All build-ups" brings them
back), and the take-off pop-out is as wide as the screen allows. Widths
tightened; "lump spread" fits its box.

Checked in a REAL browser (Chromium) at 1366px and 1600px: on the Build-ups
page and in an estimate's pop-out, a whole line fits with no sideways scroll;
VCL 1 x 0.8267 + 20% = 0.99, Discs 5 x 0.233 = 1.16, Lab 1 x 11 = 11.00. All
