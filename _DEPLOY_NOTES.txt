WHAT I DID WRONG, AGAIN
================================================================================
976 turned NAV from a module constant into navFor(term), built per render,
because two of its labels are now glossary terms.

NAV was used in TWO components in that file:

  OperationsNav   line 73   - where I declared it
  SectionTabs     line 102  - where I did not

SectionTabs is a separate component, so the NAV built in OperationsNav is not
in scope there. It referenced a module constant that no longer existed:

    ReferenceError: NAV is not defined

Twenty-five Operations pages failed to prerender - every page that renders a
second-row tab strip.

Same fault as Shell in 965 and UpcomingTable in 975: a value declared in one
component and used in another. Compiles every time.


WHY MY CHECK DID NOT CATCH IT
================================================================================
The declared-where-used scan I have been running looks at the glossary
values - term, rams, brand, money. It did not look at NAV, because NAV is not
a glossary value: it is a constant I had just converted into one.

The scan checked the thing I added and not the thing I changed.

I have now run a scope check over ALL FOUR constants converted this way -
NAV, CommercialNav's GROUPS, AdminShell's adminTabs and projects.js's
subTabs - and every reference is in a scope that declares it. The other three
were already correct; only NAV was wrong.
