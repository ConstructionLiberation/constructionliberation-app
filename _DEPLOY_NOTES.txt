LABELS ONLY. NOT KEYS, ROUTES OR STORED CATEGORIES.
================================================================================
The nav entry is:

    { key: 'rock-drawings', label: 'Drawings', slug: 'rock-drawings' }

key and slug are untouched on purpose. They are the URL
(/design/<project>/rock-drawings), the API route, the stored document
category and the design-rockdrawing-daily cron. Renaming those would break
every bookmarked link and orphan every document already filed under that
category - which is the trap the SWMS rename avoided in pkg976 and the same
reason the lost-reason values were left alone.
