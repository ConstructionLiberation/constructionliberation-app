THE PRICE LIST (Estimating > Price List)
  Upload price list   choose the file (the converter's output, or a download
                      from here, edited). It is CHECKED and summarised first -
                      products, sections, new / changed / removed, rates
                      changing, errors, warnings. NOTHING changes until Import.
                      - ERRORS block the import, listed by row (no Ref, Ref used
                        twice, a price or quantity that is not a number, a base
                        unit that is not m2 / m / nr / l / kg, quantity 0...)
                      - WARNINGS import (no price, no quantity, no base unit) -
                        those products show under Needs attention
                      An upload REPLACES the list: anything not in the file is
                      removed, and the check lists what would go.
  Download            the current list in the same format - edit in Excel and
                      upload again (round trip proven: no changes)
  Sections            down the left, plus All products and Needs attention
                      (products with no usable rate yet)
  Search              every product, by description, supplier, code or Ref
  Click a product     edit it - the rate updates as you type; or Delete
  + Add product       a new Ref is refused if already used

Every product works back to a rate per base unit (m2, m, nr, l, kg), and where
a coverage is given, a rate per m2 - the rate the estimate will use.

STORAGE: each section is stored separately, under an index. An upload writes a
complete new version first and only then switches to it - a failed upload can
never leave half a price list. Nothing is ever written on its own.
