THE FAILURE
  Module not found: Can't resolve 'async_hooks'
  ./lib/db.js <- ./lib/crmValueChanges.js <- ./lib/precontractTotals.js
  <- ./pages/scorecard-crm.js

The pre-contract scorecard is a BROWSER page and imports
lib/precontractTotals.js. 1041 made that file import two history parsers
from lib/crmValueChanges.js - which also imports the database, whose tenant
code uses async_hooks, a Node-only module. So the database code was pulled
into a browser bundle.

THE FIX
The two parsers moved, unchanged, into lib/crmHistoryParse.js, which imports
nothing. precontractTotals imports them from there. crmValueChanges imports
and re-exports them, so nothing else changes.


WHY MY CHECKS MISSED IT
I bundled every changed page as SERVER code, where async_hooks exists. From
here on, every package also bundles every page in the repo for the BROWSER
and compares against the original 1021 repo:
  157 pages checked, nothing newly failing.
And the check was proved: putting the 1041 import back in a copy fails with
exactly Vercel's error.

The pipeline and strike-rate results are identical to 1041's tests.

webhook, upload-bills, xero/backfill-labour, xero/sync - are OLD. They were
