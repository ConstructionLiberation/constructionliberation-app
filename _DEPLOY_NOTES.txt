NEW CARD, under Strike rate on value:
  Strike rate on value - existing customers

Exactly the same as Strike rate on value - rolling six months to each month
end, won value / decided value, deals with a value, last full month on the
card - but counting only deals where the customer was EXISTING when the deal
was decided: a different project won for that organisation strictly before
that day (the 1047 definition, reused, not restated). A loss is tested the
same way as a win.

Built as a filter on the all-customer strike rate, so the two always use the
same window and the same rules. A period with no existing-customer decisions
shows blank, not 0%.

If a gear order has been saved, the new card appears after the saved ones.

Checked: the rule on a set of wins and losses (all 53.3%, existing 40.0% -
the second Acme win against Acme's later loss; first wins excluded); through
the full route (June 100%, July on 40%, card to Sep 26, October blank); all
157 pages pass the browser check.
