pkg917 - CRM: pasted links in notes are clickable
==================================================

REPLACE (1 file, existing - no new files to create):

  pages/crm.js

DEPLOY AFTER pkg916, which also changes pages/crm.js. This package is built
on top of it - deploying 916 afterwards would revert this.


WHAT IT DOES
------------
A Linkify component turns http://, https:// and www. addresses in typed text
into real links. Applied in three places on the deal timeline:

  note bodies
  activity outcomes ("WHAT HAPPENED")
  comments on notes

Opens in a new tab. Nothing else about the notes changed - no editor, no
formatting, no markdown.


HOW IT IS BUILT
---------------
RENDERED AS REACT ELEMENTS, NEVER AS HTML. A note is user input, and
dangerouslySetInnerHTML on user input is how a CRM becomes an attack
surface. The text is split on the address and the pieces rendered - so a
note containing <script> is still just characters on a page.

At MODULE SCOPE, not inside the component that uses it. A component defined
inside another remounts its whole subtree on every render, which is what
caused the typing bug.

A fresh regex per call. A shared one carrying the g flag keeps lastIndex
between calls and silently skips the first match on every other render.

Trailing punctuation is left out of the link - "...deal=12094." links the
address and leaves the full stop - but a closing bracket is kept when the
address opened one.

NOT DONE
--------
Email addresses are not linked. Easy to add as mailto: if you want it - it
was not what you asked for and a mailto that opens the wrong client is more
annoying than plain text.
