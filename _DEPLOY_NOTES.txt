pkg925 - crm-daily-activities has failed every day since it was written
=======================================================================

REPLACE (1 file, existing - no new files to create):

  lib/crmDailyActivityEmail.js


THE REAL FAULT
--------------
    ReferenceError: portalUrl is not defined

buildEmail's third parameter was named `baseUrl`, which SHADOWED the
imported baseUrl() at the top of the file. The template inside it referenced
`portalUrl` - a name that exists in two other functions in that same file,
but not in this one. And the caller passed `baseUrl` (the function) rather
than `portalUrl` (the resolved string it had already worked out two lines
earlier).

A half-finished rename, in both directions at once.

It compiles. The import graph is clean. npm run build never executes it. It
only fails when the function actually RUNS - which is once a day, at 06:00
and 07:00 UTC.

So the CRM daily activity emails have NEVER been sent. Not once. pkg906
fixed the heartbeat that was hiding this, which is why it is now surfacing
as "last run failed" rather than silently succeeding.

Worth asking Edita and anyone else expecting them to confirm they start
arriving - that is the only proof.
